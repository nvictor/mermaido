# Mermaido

Your very handy MermaidJS diagram visualizer!

![Mermaido Screenshot](docs/demo.png)

- Edit Mermaid code and see the diagram render.
- Pan and zoom, with a dark mode.
- Step through a sequence diagram message by message.

Needs an internet connection: Mermaid loads from a CDN.

Requires macOS 26.0 or later and Apple Silicon.
